# FreelanceHub

A Django-based freelancing marketplace that connects clients and freelancers through a secure, role-based web application.

## 📌 Project Overview

FreelanceHub is a web application developed using Django that allows clients to post freelance jobs and freelancers to browse and apply for them. The platform includes separate dashboards for Admin, Client, and Freelancer, providing role-based access and functionality.

## ✨ Features

- User Registration and Login
- Role-Based Authentication (Admin, Client, Freelancer)
- Client Dashboard
- Freelancer Dashboard
- Job Posting and Management
- Browse Available Jobs
- Submit Job Proposals
- Profile Management
- Responsive User Interface
- Admin Panel for System Management

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/FreelanceHub.git
```

### 2. Navigate to the project

```bash
cd FreelanceHub
```

### 3. Create a virtual environment

```bash
python -m venv myenv
```

### 4. Activate the virtual environment

**Windows**

```bash
myenv\Scripts\activate
```

**Linux / macOS**

```bash
source myenv/bin/activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Apply migrations

```bash
python manage.py migrate
```

### 7. Run the development server

```bash
python manage.py runserver
```

Open your browser and visit:

```
http://127.0.0.1:8000/
```
